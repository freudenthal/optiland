Anisotropic Media and Ray Splitting
===================================

Examples of crystals in sequential systems: tensor materials, the plane-wave
modes of an interface, tracing one mode through a crystal, splitting rays into
every mode and ghost, folds inside crystals, optical activity and diffraction
orders as branches. Each example compares the trace with closed forms.
